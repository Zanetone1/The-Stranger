# L'Étranger — an interactive reading

An interactive site about Albert Camus's *The Stranger* by Christian Angelo.

- `content.js` — all the writing on the site. Edit this to change any text.
- `index.html` — page structure
- `style.css` — design (colours and fonts are at the top)
- `script.js` — interactions (heat gauge, sun, beach shade, knocks, jury, stars)

Plain static site: no build step. Deployed on Vercel from the `main` branch.
